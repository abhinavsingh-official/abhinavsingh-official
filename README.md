### About

AI Associate working across machine learning, computer vision, and NLP. I like
projects that do one real thing well over ones that look impressive and fall
apart under a second look - every repo below runs, has tests, and has CI
that's actually green.

### Pinned work

| Project | What it does |
|---|---|
| [Posture-Check](https://github.com/abhinavsingh-official/Posture-Check) | A multi-mode OpenCV/MediaPipe playground - yoga form correction, workout rep counting, hand-gesture stickers, an air canvas, a virtual mouse, and a drowsiness monitor, all in one app |
| [EmotionDetect](https://github.com/abhinavsingh-official/EmotionDetect) | Voice emotion detection with a real timeline mode for longer clips and conversations, not just single-utterance classification |
| [SentimentAutomated](https://github.com/abhinavsingh-official/SentimentAutomated) | Live sentiment ingestion and analysis pipeline with heatmap reporting |
| [RAGReliabilityChecker](https://github.com/abhinavsingh-official/RAGReliabilityChecker) | Checks whether a RAG answer is actually grounded in its retrieved context - span-level hallucination detection, not another chatbot |
| [SafeNL2SQL](https://github.com/abhinavsingh-official/SafeNL2SQL) | Natural-language-to-SQL where a sqlglot-based safety layer validates every generated query before it touches a database |
| [DriftWatchdog](https://github.com/abhinavsingh-official/DriftWatchdog) | Statistical drift detection and real accuracy tracking for a deployed classifier |
| [BlurGate](https://github.com/abhinavsingh-official/BlurGate) | A classical and a learned blur detector scored side by side as a document/photo quality gate |
| [SkillGapMatcher](https://github.com/abhinavsingh-official/SkillGapMatcher) | ATS-style resume-to-job-description matcher with an explicit skills-gap breakdown |
